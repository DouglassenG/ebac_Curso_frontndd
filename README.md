## 🎯 Motivação e Propósito

O propósito deste repositório é documentar a **trajetória de aprendizado**. Em vez de manter códigos fragmentados em pastas locais, este projeto serve como um histórico vivo da evolução técnica.

Ele resolve o desafio de organização de estudos, permitindo comparação entre códigos antigos (fundamentos) e novos (arquiteturas modernas), além de servir como biblioteca de consulta para soluções de layouts, animações CSS e funções JavaScript.

## 🛠️ Tecnologias Utilizadas

A stack tecnológica abrange todo o ciclo básico e intermediário do desenvolvimento web:

* **Fundamentos:** [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) semântico e [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) (Flexbox/Grid).
* **Pré-processadores:** [SASS](https://sass-lang.com/) para estilos modulares e variáveis.
* **Lógica e DOM:** [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) Vanilla e bibliotecas como jQuery.
* **Automação (Build Tools):** [Gulp](https://gulpjs.com/) ou Grunt para otimização de imagens, minificação de scripts e compilação de estilos.
* **Controle de Versão:** Git e GitHub Flow.

## 📦 Instalação e Configuração

Como este repositório contém múltiplos projetos, a configuração depende do módulo que você deseja executar.

### Pré-requisitos
* **Node.js** (LTS) instalado.
* **Git** instalado.

### Passo a Passo Geral

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/DouglassenG/ebac_Curso_frontndd.git](https://github.com/DouglassenG/ebac_Curso_frontndd.git)
    ```

2.  **Acesse o diretório:**
    ```bash
    cd ebac_Curso_frontndd
    ```

3.  **Para Módulos com Automação (Gulp/Grunt):**
    Navegue até a pasta do exercício específico e instale as dependências:
    ```bash
    cd nome-da-pasta-do-exercicio
    npm install
    npm run build
    ```

4.  **Para Módulos Estáticos:**
    Basta abrir o arquivo `index.html` diretamente no navegador.
